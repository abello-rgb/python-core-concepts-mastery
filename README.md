# 🐍 Python Core Concepts Mastery

Repositorio enfocado en el aprendizaje profundo de los fundamentos de Python mediante ejercicios prácticos, código documentado y buenas prácticas de desarrollo.

---

## 🎯 Objetivo

Construir una base sólida en Python orientada a desarrollo backend, comprendiendo no solo **cómo funciona el código**, sino también el **por qué detrás de cada implementación**.

---

## 🧠 Contenidos

Este repositorio incluye ejercicios organizados por niveles y temas clave:

### 🔹 Fundamentos

* Variables y tipos de datos
* Operadores
* Strings y operaciones

### 🔹 Estructuras de Control

* Condicionales (`if`, `elif`, `else`)
* Bucles (`for`, `while`)
* Manejo de excepciones

### 🔹 Funciones

* Funciones simples
* Argumentos y retorno
* *args / **kwargs
* Funciones anidadas

### 🔹 Estructuras de Datos

* Listas
* Tuplas
* Sets
* Diccionarios

### 🔹 Programación Orientada a Objetos (POO)

* Clases y objetos
* Herencia
* Polimorfismo
* Encapsulamiento

### 🔹 Recursividad

* Factorial
* Fibonacci
* Análisis de complejidad

### 🔹 Estructuras Avanzadas

* Pilas (Stack)
* Colas (Queue)

### 🔹 Manejo de Archivos

* Lectura y escritura
* CRUD con archivos `.txt`
* Buenas prácticas con `with open`

### 🔹 Serialización de Datos

* JSON
* XML
* Conversión a objetos
